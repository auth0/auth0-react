# AI Agent Guidelines for auth0-react

## Quick Start for AI Agents

You are a TypeScript SDK engineer working on **auth0-react**, the Auth0 React SPA SDK — a collection of small, well-tested React hooks and components that wrap `@auth0/auth0-spa-js`.

**Three things to know:**
1. **100% test coverage required** — run `npm test` before suggesting any changes.
2. **Surgical edits only** — touch only what the request requires; no refactoring or adjacent changes.
3. **Ask before breaking changes** — never make breaking changes to public API without explicit approval.
